# Security policy

## Supported status

This repository is an educational, pre-release project. No implementation
version is currently supported for production or security-sensitive use.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential,
or sensitive data leak. Use GitHub’s private vulnerability reporting feature
when it is enabled for the repository. If it is unavailable, contact the
repository owner privately through the owner’s GitHub profile and provide:

- the affected revision and file;
- the impact and required preconditions;
- a minimal reproduction when safe;
- whether any credential or private data may already be exposed.

Do not test against systems, accounts, or data you do not own or have explicit
permission to use.
