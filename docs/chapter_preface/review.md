# Preface review

## Takeaways

- The project is a learning stack, not only an operator library.
- Exact contracts connect the graph, compiler, runtime, model, and evidence.
- YOLOv8n is the main application; advanced tracks do not block it.
- Documentation is reviewable now, while executable claims remain unverified.

## Check your understanding

1. Why is a correct NumPy output insufficient evidence for the whole stack?
2. Which boundary turns compiler output into a runtime/device agreement?
3. Why are functional, timing, and RTL models introduced in that order?
4. What must change before an experimental result can be recorded as evidence?
