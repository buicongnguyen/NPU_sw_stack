# Chapter 2 summary and review

## Summary

Evidence is a structured artifact, not a confident sentence. The project
journal distinguishes decisions, local checks, and observations so that future
readers can see exactly what was and was not reproduced.

## Review questions

1. Why must the commit identifier be recorded with a result?
2. What is missing when a log contains output but not the command or input?
3. When may a local static inspection be upgraded to observed evidence?
4. Why should a CPU reference be established before accelerator measurements?

## Deferred lab

Create a clean WSL environment, record all tool versions, run the smallest CPU
reference, and add a dated journal entry using the
[entry template](../_drafts/progress-entry-template.md).
