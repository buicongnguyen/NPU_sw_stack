# Chapter 10 summary and review

## Summary

Performance claims require named assumptions, measured counters, and preserved
correctness. RTL is introduced only after the functional boundary is stable
enough to make comparison meaningful.

## Review questions

1. Why can two correct schedules have different cycle counts?
2. What denominator defines array utilization?
3. Which traffic should count as compulsory versus avoidable?
4. What can a timing model predict that a functional model cannot?
5. Which differences between timing model and RTL are acceptable?

## Deferred lab

Instrument one GEMM tile, predict cycles and traffic, and compare the prediction
with a small RTL simulation. Record both the result and every modeling
assumption.
