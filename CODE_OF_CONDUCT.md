# Code of conduct

This project is a technical learning space. Participants are expected to be
respectful, precise, patient, and constructive.

Welcomed behavior includes:

- questioning ideas without attacking people;
- stating assumptions and evidence;
- helping newcomers understand project terminology;
- crediting sources and prior work;
- acknowledging mistakes and correcting the record.

Harassment, discrimination, threats, sexualized conduct, deliberate
misinformation, credential exposure, or repeated disruption are not accepted.

Repository maintainers may edit, hide, reject, or remove contributions and may
restrict participation when needed to protect the project and its community.
Report conduct concerns privately through the repository owner’s GitHub
profile. Do not include sensitive personal information in a public issue.
